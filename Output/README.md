# Output Folder

## Overview

This folder stores all final outputs generated by the project's analytical pipeline, including empirical tables, graphical figures, and supplementary documentation products.

## Contents

- **[`Results/`](file:///e:/Github/cfa-power/Output/Results/)**: Contains the primary empirical results of the study:
  - `Figures/`: 21 high-resolution plots (`.png`).
  - `Tables/`: 14 standalone datasets/tables (`.csv`).
- **[`DataAppendixOutput/`](file:///e:/Github/cfa-power/Output/DataAppendixOutput/)**: Contains supplementary documentation, codebooks, and verification logs detailing data preparation.

## Provenance and Usage

- **Origin**: Generated by the computational notebooks in [`Scripts/AnalysisScripts/`](file:///e:/Github/cfa-power/Scripts/AnalysisScripts/) (01 to 06) and synchronized via post-render routines.
- **Destination**: These files directly feed the tables, diagrams, and power curves presented throughout the main manuscript ([`index.qmd`](file:///e:/Github/cfa-power/index.qmd)), while also serving as standalone, reusable artifacts for replication.
- **Regeneration**: To regenerate all figures and tables from scratch, run `quarto render` in the project root.

For a detailed file-by-file mapping of all tables and figures to the manuscript, see [`Output/Results/README.md`](file:///e:/Github/cfa-power/Output/Results/README.md).
