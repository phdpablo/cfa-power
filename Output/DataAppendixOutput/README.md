# Data Appendix Output Folder

## Overview

This folder stores supplementary documentation products, codebooks, and audit summaries that support the project's data appendix.

## Contents

- **Data Documentation**: Codebooks, variable definition files, and scale descriptions for the WHOQOL-BREF dataset.
- **Audit Logs**: Logs and summary statistics verifying raw data retrieval, transformation steps, and distribution checks.
- **Environment Snapshots**: Computational environment and session information records (`sessionInfo()`, package versions).

## Provenance and Usage

- **Origin**: Generated by auxiliary documentation and audit routines located in [`Scripts/DataAppendixScripts/`](file:///e:/Github/cfa-power/Scripts/DataAppendixScripts/).
- **Destination**: Accompanies the published data appendix to ensure complete transparency of data custody and processing.
