# Results Folder

## Overview

This folder stores the final tables and figures generated by the analysis notebooks. These files represent the primary empirical results of the study and are embedded directly into the main manuscript ([`index.qmd`](file:///e:/Github/cfa-power/index.qmd)).

## Contents

- **`Tables/`**: 14 standalone tables in CSV format (`.csv`).
- **`Figures/`**: 21 high-resolution images in PNG format (`.png`).

## Regeneration

All tables and figures are automatically updated whenever the project is rendered:

```bash
quarto render
```

Post-render scripts (`post_render_figures.R` and `post_render_tables.R`) extract new outputs directly from rendered HTML files and update this directory.
