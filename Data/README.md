# Data Folder

## Overview

This folder organizes all data assets utilized in the project. It separates raw input specifications, computationally intensive intermediate simulation caches, and analysis-ready datasets.

## Contents

- **[`InputData/`](file:///e:/Github/cfa-power/Data/InputData/)**: Contains original parameter files and metadata documenting the population models:
  - `popmodels_parameters.csv`: Meta-analytic parameter definitions for the four population models (`popmodel`, `naivemodel`, `optmodel`, `h1model`).
  - `Metadata/`: Documentation of data sources, item definitions, and parameter derivation methods.
- **[`IntermediateData/`](file:///e:/Github/cfa-power/Data/IntermediateData/)**: Contains 12 serialized simulation objects (`.rds` files) generated by `simsem`. These cached simulations allow rapid rendering and reproduction without repeating thousands of Monte Carlo replications.
- **[`AnalysisData/`](file:///e:/Github/cfa-power/Data/AnalysisData/)**: Reserved for final processed analysis datasets. In this simulation-based study, data are primarily generated dynamically in-memory or retrieved directly from public repositories.

## Provenance and Usage

- **Origins**:
  - Parameter values in `InputData/` are derived from the meta-analysis by Lin & Yao (2022) and the systematic review by Mosqueira-Taipe et al. (2026).
  - Empirical benchmark data are retrieved programmatically from Mendeley Data (Rogers, 2022).
  - Intermediate `.rds` files are generated by computational scripts in `Scripts/AnalysisScripts/` and `Scripts/DataAppendixScripts/`.
- **Destinations**:
  - `popmodels_parameters.csv` feeds `01_population_models.qmd` to produce summary comparison tables.
  - Intermediate `.rds` files feed the inline code and results in `index.qmd` as well as companion notebooks `03` through `06`.

For specific details on individual datasets and cached models, consult the `README.md` in each respective subfolder.
