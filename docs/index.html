Abstract

This notebook presents a pedagogical tutorial on statistical power analysis in Confirmatory Factor Analysis (CFA). Proper planning of sample sizes requires assessing the power to detect overall model misfit by analytical approach or simulation-based approach. Standard analytical tools typically rely on asymptotic normal theory, which may break down when confronted with non-normality or missing data. This tutorial demonstrates both analytical strategies (using semPower and semTools) and Monte Carlo simulations (using simsem) side-by-side using the WHOQOL-BREF 4-factor model as a unifying case study. We illustrate how simulation can complement analytical calculations, allowing researchers to evaluate parameter-level power, coverage, and relative bias under realistic scenarios involving varying degrees of model misspecification, missing data, and continuous non-normal indicators. Ultimately, we argue that analytical methods are ideal for initial planning, while simulations constitute the gold standard for robust confirmation.

1 Introduction

Statistical power in Confirmatory Factor Analysis (CFA) reflects the probability of correctly rejecting an incorrectly specified model, or detecting a parameter of interest when it is truly non-zero in the population (MacCallum et al., 1996). Power analysis is critical when planning a CFA study; however, researchers often rely on arbitrary rules of thumb mapping required sample sizes to the number of measured variables or parameters, rather than formal prospective calculations.

There are two main paradigms to power analysis in CFA:

  1. Analytical methods: Rely on asymptotic statistical theory (e.g., the non-central \(\chi^2\) distribution) to calculate the required sample size for detecting global model misfit based on established fit indices like the RMSEA (Moshagen & Bader, 2024).
  2. Simulation-based methods: Use Monte Carlo data generation to repeatedly establish how the model behaves under assumed population models, allowing the estimation of power, bias, and coverage for specific parameters or overall fit indices across varying sample sizes (Pornprasertmanit et al., 2021).

This document provides a comprehensive tutorial covering both analytical methods using the semPower and semTools packages, and Monte Carlo methods using the simsem package.

The results throughout this tutorial will thus show more sampling variability than you would expect in a final study. All analytical and simulation parameters are centrally defined in helpers.R and models.R.

2 The Running Example: WHOQOL-BREF Population CFA Model

To anchor our power analyses, we use the WHOQOL-BREF measurement instrument. Meaningful power analysis requires the definition of a population model—the “true” state of the world from which we believe our data are generated. By simulating from a meta-analytically derived population model rather than a purely arbitrary one, researchers can ensure that tests reflect realistic boundaries (Lin & Yao, 2022).

We specify four population variations to perform sensitivity analyses:

  1. Meta-analytic: Loadings and residual variances closely matching Lin & Yao (2022).
  2. Naive: A pessimistic baseline where factor loadings are based on the lowest reported reliability values per domain (Mosqueira Taipe et al., 2026).
  3. Optimistic: A best-case scenario where factor loadings are based on the highest reported reliability values per domain (Mosqueira Taipe et al., 2026).
  4. H1: A misspecified model with cross-loadings based on the meta-EFA results from Lin & Yao (2022).

2.6 Analysis model

The analysis model serves dual purposes depending on the simulation paradigm:

  • Paradigm A (Recovery power): Estimates the 4-factor structure plus the \(Q3\) and \(Q4\) residual covariance given data from the meta-analytic, naive, or optimistic population models.
  • Paradigm B (Misspecification detection): Acts as the null hypothesis (\(H_0\)), meaning it omits the cross-loadings, when fitting data generated from the misspecification model (\(H_1\)). Here, power is the probability of correctly rejecting the model given that cross-loadings exist in the population.

Key constraints and features:

  • Identification: Factor variances are fixed to \(1\) (marker-free scaling) allowing the first indicator to be freely estimated.
  • Residual covariance: \(Q3\) and \(Q4\) correlation is freely estimated, which is theoretically justified and empirically supported (Lin & Yao, 2022; Mosqueira Taipe et al., 2026).
  • Cross-loadings: The omission of cross-loadings for items \(Q8\), \(Q9\), and \(Q15\) deliberately defines the misspecification tested in Paradigm B.

3 Analytical Power Analysis

Analytical power usually asks: “How large must \(N\) be to reject the hypothesis that the model fits perfectly (or adequately) when the true misfit in the population is of a certain magnitude?” A common formulation sets the alternative hypothesis to RMSEA = 0.05 (MacCallum et al., 1996).

3.1 Model Degrees of Freedom

Analytical calculations depend crucially on model degrees of freedom (\(df\)), the difference between the number of available pieces of information (unique variances/covariances) and the number of freely estimated parameters. Knowing this allows tools to parameterize the non-central \(\chi^2\) distribution. This calculation is necessary for both a priori and post hoc power analyses in analytical methods for global fit.

ImportantLimitations of the Analytical Approach

The RMSEA/\(\chi^2\)-based analytical method classically assumes continuous, multivariate normal data and Maximum Likelihood estimation. It can yield severely biased optimal sample sizes when distributions are non-normal, data are ordinal, or missingness induces efficiency losses. Furthermore, it measures power regarding global misfit, telling us nothing about whether \(N\) is adequate to detect a specific weak loading or structural path.

8 When to Use What: Analytical vs. Simulation

Feature Analytical (semPower/semTools) Simulation (simsem)
Speed Instantaneous Minutes to hours
Handles non-normality effectively No Yes
Handles missing data mechanism No Yes
Parameter-level power targeting Very Limited Comprehensive
Coverage / relative bias diagnostics No Yes
Primary Use-Case Grant planning, quick rough parameterization bounds Pre-registration confirmation, sensitivity checks, final reporting

Best Practice Recommendation: Define theoretical bounds mapping an expected scenario utilizing fast analytical approximations. Validate robust tolerance to observed/anticipated data flaws (e.g., missingness, skew, differing distributions) iteratively through explicit simulation runs before finalizing sample specifications.
