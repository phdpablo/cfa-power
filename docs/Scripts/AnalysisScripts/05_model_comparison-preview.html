Power analysis with fixed N

The preceding sections determined the minimum \(N\) required to achieve adequate power across a range of conditions. This section takes a different perspective: rather than searching for the smallest sufficient sample size, it fixes \(N = 350\) and asks how reliably that value sustains the target power under the most demanding combined scenario — 10% MCAR missingness and mild non-normality simultaneously (Feng & Hancock, 2023; Pornprasertmanit et al., 2021).

This design choice reflects a common applied situation in which the sample size is constrained by practical or budgetary considerations. Running a large number of replications at a fixed \(N\) provides a direct stability check: if power remains consistently above the target across many random samples, the chosen sample size can be considered a robust planning value for the full research design (Jobst et al., 2023; Wang & Rhemtulla, 2021).

Power curves for fit indices

With \(N\) fixed, plotPowerFit() no longer traces power as a function of sample size. Instead, the figure displays the empirical distributions of each fit index under the reference and misspecified conditions across replications, alongside the cutoff derived from the reference model at the chosen \(\alpha\) level. The visual separation between the two distributions is the graphical counterpart of the power values reported in the table below (McNeish & Wolf, 2021; Pornprasertmanit et al., 2021).

In [4]:

plotPowerFit(
    h1model_fixed,
    popmodel_fixed,
    alpha = ALPHA,
    usedFit = FITS
)

Power and cutoff values for fit indices

In [5]:

# Estimate power for rejecting the misspecified model (h1model_fixed)
# using fit-index cutoffs implied by the null model.
power_fixed <- getPowerFit(
  h1model_fixed,
  nullObject = popmodel_fixed,
  alpha = ALPHA,
  usedFit = FITS
)

# Derive empirical cutoff values for the selected fit indices
# from the null-model sampling distribution under the same conditions.
cutoff_fixed <- getCutoff(
  popmodel_fixed,
  alpha = ALPHA,
  usedFit = FITS
)

# Combine power and cutoff values into a compact summary table.
power_cutoff_fixed <- rbind(
  "Power" = as.numeric(power_fixed),
  "Cutoff" = as.numeric(cutoff_fixed[1, ])
)

Power analysis with traditional cutoffs

The same fixed-\(N\) simulation is now re-evaluated using conventional rule-of-thumb thresholds in place of the empirically derived cutoffs used above. This is a deliberate contrast: by holding \(N\), the data-generating model, and the analysis model constant while changing only the decision criterion, the comparison isolates the contribution of the cutoff choice to the power conclusion (Kyriazos, 2018; McNeish & Wolf, 2021).

In [7]:

plotPowerFit(
    h1model_fixed,
    popmodel_fixed,
    cutoff = RULE_OF_THUMB,
    alpha = ALPHA,
    usedFit = FITS
)
In [8]:

# Estimate power using traditional fit-index cutoffs.
power_traditional <- getPowerFit(
  h1model_fixed,
  RULE_OF_THUMB,
  alpha = ALPHA,
  usedFit = FITS
)

# Convert to a one-row table with column headers.
power_traditional_tbl <- t(as.data.frame(power_traditional))

colnames(power_traditional_tbl) <- toupper(names(power_traditional))
rownames(power_traditional_tbl) <- "Power"

knitr::kable(power_traditional_tbl, digits = 3, align = "c")
